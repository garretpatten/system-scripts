Privacy Policy

This privacy policy applies to Personal Calendar Tasks Brief, a personal, single-user tool. Effective date: November 21, 2026.

What Google user data is accessed

The app accesses the following Google user data, using the corresponding OAuth scopes:

  • Google Calendar events — scope https://www.googleapis.com/auth/calendar.readonly
  • Google Tasks — scope https://www.googleapis.com/auth/tasks.readonly

Both scopes are read-only. The app never writes to Calendar or Tasks.

Purpose

The app reads the account owner's Google Calendar events and Google Tasks for the day to generate a personal morning brief (summary) for that same account owner. It is not used for any other purpose.

Sharing, advertising, and retention

  • Data is not shared with third parties.
  • Data is not used for advertising.
  • Data is not sold or transferred to anyone.
  • Data is not retained on any server controlled by the developer. The brief is generated with only the temporary processing needed for that request. OAuth tokens stay with the owner's own tooling on their own machine.

How to revoke access

You can revoke this app's access at any time by visiting your Google Account at Security → Third-party access (or via myaccount.google.com/permissions) and removing the app's access.

Contact

Limited Use compliance

Personal Calendar Tasks Brief's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
